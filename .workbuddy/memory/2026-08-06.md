## 修复 front 项目 build 失败问题

### 问题1：OOM Killed（内存不足）
- 服务器内存不足，Next.js 16 build 被 OOM Killer 杀掉
- 解决：加 4-8GB swap + `NODE_OPTIONS="--max-old-space-size=4096"`

### 问题2：预渲染时 fetch 超时（10.9.0.10:3001 不可达）
- `/literacy`、`/scenes/[key]`、`/tool/[slug]`、`/usages/[id]` 4个服务端组件页面在 build 时尝试 fetch admin API
- .env.local 中 NEXT_PUBLIC_API_BASE=http://10.9.0.10:3001 是本地局域网 IP，服务器不可达
- 解决：给这4个页面添加 `export const dynamic = 'force-dynamic'`
  - 跳过 build 时预渲染，改为运行时 SSR
  - generateStaticParams 在 force-dynamic 下被忽略
  - 页面在运行时渲染，此时 admin API 已通过 PM2 启动
- 还原了 next.config.ts 中临时添加的 typescript.ignoreBuildErrors 和 eslint.ignoreDuringBuilds
- 服务器上需创建 .env.production 设置正确的 NEXT_PUBLIC_API_BASE（admin 公网地址）

### 问题3：预渲染时 admin.eanavi.com ENOTFOUND
- 服务器上 .env.production 改成了 admin.eanavi.com，但域名 DNS 还没解析
- 且代码改动（force-dynamic）没 git pull 到服务器
- 解决：content.ts 的 fetch 包裹 safeFetch，build 时 admin API 不可达返回空数据而非崩溃
- 已 commit + push（126027d），服务器需 git pull + 清 .next + 重新 build
